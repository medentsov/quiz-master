# Quiz Master — викторина по вопросам с viktorinavopros.ru

Android-приложение на Kotlin + Jetpack Compose в формате интеллектуальной
викторины. Вопросы и ответы загружаются с сайта
[viktorinavopros.ru](https://viktorinavopros.ru/) и автоматически раскладываются
по категориям.

## Возможности

- Загрузка вопросов и ответов через WordPress REST API сайта.
- Разбор нумерованных вопросов и секции «Ответы».
- Автоматическая классификация по 14 темам (литература, география, спорт,
  кино, наука, природа, еда, СССР и другие). Категории эвристические, поэтому
  часть вопросов попадает в «Разное».
- Игровое табло: от 1 до 6 категорий по 5 вопросов стоимостью от 100 до
  500 баллов.
- Одиночная игра или до 12 игроков с именами и индивидуальным счётом.
- Свободный ввод ответа: вариантов ответа нет, игрок вводит ответ вручную.
- Умная проверка ответа:
  - не важен регистр букв, «ё» и пунктуация;
  - не важен порядок слов;
  - даты принимаются в разных форматах (`24 марта 1984 года`,
    `24.03.1984`, `24.03.84`, `1984-03-24`);
  - допускаются небольшие опечатки — до двух букв;
  - падежные окончания не считаются ошибкой;
  - неполный ответ считается верным, если все слова игрока есть в правильном
    ответе.
- Необязательный таймер на 30 секунд или 1 минуту. Отсчёт начинается через
  5 секунд после открытия вопроса, чтобы игрок успел прочитать условие.
- Ненавязчивое тиканье часов во время отсчёта.
- Спокойный монотонный фоновый эмбиент без пауз между повторами, который можно
  включить или выключить на главном экране.
- Выбор звука верного и неверного ответа из выпадающих списков на главном
  экране. Выбор запоминается.
- Реакции хомяка-маскота и звуковые эффекты.
- Ход переходит следующему игроку после каждого вопроса.
- Верный ответ прибавляет стоимость вопроса, ошибка или истёкший таймер
  отнимает её.
- Итоговый экран: победитель, таблица игроков и разбор всех ответов
  с фильтрами «Все / Верные / Ошибки».
- Кэширование загруженных данных: приложение открывается офлайн и обновляет
  вопросы в фоне.

## Как играть

1. На стартовом экране выберите количество игроков (от 1 до 12) и при
   желании введите имена.
2. При необходимости включите таймер на 30 секунд или 1 минуту и фоновый
   эмбиент.
3. Нажмите «Начать игру».
4. Выберите от 1 до 6 категорий для табло.
5. Игроки по очереди выбирают категорию и стоимость вопроса.
6. Введите ответ и нажмите «Ответить». Если включён таймер, на ответ даётся
   выбранное время после пятисекундной паузы.
7. После ответа нажмите «Продолжить» — ход перейдёт следующему игроку.
8. В любой момент игру можно завершить и посмотреть итоги.

## Сборка

Требования:

- JDK 17;
- Android SDK с `compileSdk 37`;
- Android Studio (рекомендуется) или Gradle 9.6.

Через Gradle wrapper:

```bash
export ANDROID_HOME="$HOME/Android/Sdk"
export JAVA_HOME="$HOME/android-studio/jbr"   # путь к JDK 17
./gradlew :app:assembleDebug
```

Готовый APK:

```
app/build/outputs/apk/debug/app-debug.apk
```

Установка на подключённое устройство или эмулятор:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n ru.viktorinavopros.quiz/.MainActivity
```

## Тесты

```bash
./gradlew :app:testDebugUnitTest
```

Тесты проверяют разбор реального HTML, классификатор тем, создание табло,
проверку свободных ответов (даты, порядок слов, падежи, опечатки, неполные
ответы), начисление баллов, тайм-аут, переход хода и завершение игры.

```
app/src/main/java/ru/viktorinavopros/quiz/
├── MainActivity.kt
├── audio/
│   └── AppSounds.kt         эмбиент, тиканье и звуковые эффекты

├── game/
│   ├── AnswerChecker.kt     умная проверка свободного ответа

│   └── GameFactory.kt       создание табло и игроков
└── ui/
    ├── App.kt               навигация между экранами
    ├── AppViewModel.kt      состояние приложения и действия игры
    ├── components/          общие компоненты
    ├── screens/             старт, категории, табло, результаты
    └── theme/               синяя тема с золотыми акцентами
```

## Аудио

- Фоновый эмбиент: [Ambient Relaxing Loop](https://opengameart.org/content/ambient-relaxing-loop)
  by isaiah658, CC0. Воспроизводится бесшовно двумя плеерами.
- Тиканье часов: [Ticking Clock](https://opengameart.org/content/ticking-clock-0),
  CC0.
- Звуки верного и неверного ответа: пользовательские аудиофайлы, названия
  вариантов взяты из имён файлов.

## Примечания

- Приложение не является официальным и не связано с сайтом

- Вопросы и ответы принадлежат их авторам и сайту-источнику.
- Для работы онлайн-обновления нужен доступ в интернет; после первой загрузки
  вопросы сохраняются локально.
