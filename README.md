# Своя игра — викторина по вопросам с viktorinavopros.ru

Android-приложение на Kotlin + Jetpack Compose, оформленное как телевикторина
«Своя игра». Вопросы и ответы загружаются с сайта
[viktorinavopros.ru](https://viktorinavopros.ru/) и автоматически раскладываются
по категориям.

## Возможности

- Загрузка вопросов и ответов через WordPress REST API сайта.
- Разбор нумерованных вопросов и секции «Ответы».
- Автоматическая классификация по 14 темам (литература, география, спорт,
  кино, наука, природа, еда, СССР и другие). Категории эвристические, поэтому
  часть вопросов попадает в «Разное».
- Игровое табло в стиле «Своей игры»: от 1 до 6 категорий по 5 вопросов
  стоимостью от 100 до 500 баллов.
- Одиночная игра или до 12 игроков с именами и индивидуальным счётом.
- Вопрос с четырьмя вариантами ответа; верный ответ подсвечивается зелёным,
  неверный — красным.
- Реакции хомяка-маскота, фон дождя и звуковое сопровождение с возможностью
  полностью отключить звук.
- Ход переходит следующему игроку после каждого вопроса.
- Верный ответ прибавляет стоимость вопроса, ошибка — отнимает.
- Итоговый экран: победитель, таблица игроков и разбор всех ответов
  с фильтрами «Все / Верные / Ошибки».
- Кэширование загруженных данных: приложение открывается офлайн и обновляет
  вопросы в фоне.

## Как играть

1. На стартовом экране выберите количество игроков (от 1 до 12) и при
   желании введите имена.
2. Нажмите «Начать игру».
3. Выберите 6 категорий для табло (или нажмите «Случайные 6»).
4. Игроки по очереди выбирают категорию и стоимость вопроса.
5. После ответа нажмите «Продолжить» — ход перейдёт следующему игроку.
6. В любой момент игру можно завершить и посмотреть итоги.

## Сборка

Требования:

- JDK 17;
- Android SDK с `compileSdk 37`;
- Android Studio (рекомендуется) или Gradle 9.6.

Через Gradle wrapper:

```bash
export ANDROID_HOME="$HOME/Android/Sdk"
export JAVA_HOME="$HOME/android-studio/jbr"   # путь к JDK 17
./gradlew :app:assembleDebug
```

Готовый APK:

```
app/build/outputs/apk/debug/app-debug.apk
```

Установка на подключённое устройство или эмулятор:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n ru.viktorinavopros.quiz/.MainActivity
```

## Тесты

```bash
./gradlew :app:testDebugUnitTest
```

Тесты проверяют разбор реального HTML, классификатор тем, генерацию вариантов
ответа, полный разбор сохранённого ответа API (если файл
`/tmp/opencode/posts.json` существует) и игровую логику: начисление баллов,
переход хода и завершение игры.

## Структура проекта

```
app/src/main/java/ru/viktorinavopros/quiz/
├── MainActivity.kt
├── data/
│   ├── Models.kt            модели вопросов, тестов и тем
│   ├── QuizParser.kt        разбор вопросов и секции «Ответы»
│   ├── TopicClassifier.kt   классификация по ключевым словам
│   └── SiteRepository.kt    загрузка API, кэш и сборка данных
├── game/
│   ├── GameModels.kt        игроки, табло, состояние и подсчёт очков
│   └── GameFactory.kt       генерация табло и вариантов ответа
└── ui/
    ├── App.kt               навигация между экранами
    ├── AppViewModel.kt      состояние приложения и действия игры
    ├── components/          общие компоненты
    ├── screens/             старт, категории, табло, результаты
    └── theme/               синяя тема с золотыми акцентами
```

## Примечания

- Приложение не является официальным и не связано с сайтом
  viktorinavopros.ru.
- Вопросы и ответы принадлежат их авторам и сайту-источнику.
- Для работы онлайн-обновления нужен доступ в интернет; после первой загрузки
  вопросы сохраняются локально.
