# Хомяк и орех — пример анимации

Отдельный пример визуального фидбека для «Своей игры»: у хомяка уже полные
щёки, он поднимает орех, отправляет его в левую щёку и довольно жмурится.

**Код Android-приложения не изменялся.** Эта папка не подключена к сборке.

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | Страница просмотра: повтор, прозрачный фон, скачивание |
| `hamster.webp` | Основная анимация, 600×600, 20 fps, 3 с, цикл |
| `hamster.gif` | GIF-версия, 480×480 (для мессенджеров и презентаций) |
| `hamster.mp4` | H.264, 600×600, 3 с (для видео) |
| `hamster-alpha.webp` | Версия с прозрачным фоном |
| `poster.png` | Кадр-постер |
| `make_hamster.py` | Генератор: Pillow + numpy + ffmpeg |

## Как посмотреть

```bash
cd animations/hamster
python3 -m http.server 8765
```

Открыть <http://localhost:8765/>.

## Как пересобрать

```bash
cd animations/hamster
python3 make_hamster.py
```

Нужны Python 3, Pillow, numpy и ffmpeg.

## Сценарий (3 секунды)

1. `0.00–0.14` — хомяк тянется лапой вправо, орех проявляется.
2. `0.14–0.46` — орех поднимается к мордочке, лапа держит его снизу.
3. `0.46–0.56` — орех уходит за левую щёку (рисуется под ней).
4. `0.56–0.78` — щека раздувается, «поп»-кольцо, искры, лёгкий подскок.
5. `0.78–1.00` — хомяк жмурится, щека постепенно возвращается к исходной.
